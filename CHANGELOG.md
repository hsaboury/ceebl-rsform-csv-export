# Changelog

All notable changes to Joomlog RSForm CSV Export will be documented in this file.

The project follows the principles of [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and intends to use [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [1.2.0] - 2026-10-21

### Changed

- Rebrand the plugin from Ceebl RSForm CSV Export to Joomlog RSForm CSV Export.
- Update English and Persian plugin display names.
- Update plugin metadata to identify Joomlog as the publisher.
- Update source file headers and project documentation to reflect the Joomlog brand.
- Preserve the existing Joomla plugin element (`csvprobe`) and PHP namespace for backward compatibility.

## [1.1.1] - 2026-10-18

### Added

- Add English and Persian (fa-IR) localization for plugin settings.
- Add localized inline help descriptions for all configuration fields.
- Add localized plugin name and description.

### Changed

- Replace hardcoded configuration labels and descriptions with Joomla language constants.
- Package language files within the plugin for Joomla 6 compatibility.
- Use Joomla's built-in Toggle Inline Help functionality without custom JavaScript or CSS.

## [1.1.0] - 2026-10-17

### Documentation

- Add README, changelog, and GPL-2.0-or-later licensing information.

### Added

- Configurable Excel UTF-8 compatibility fix.
- Optional CSV download restrictions based on Joomla user groups.
- Configuration for selecting authorized user groups.
- Optional hiding of CSV export buttons for unauthorized users.
- Server-side HTTP 403 protection for unauthorized directory CSV downloads.

### Fixed

- PHP deprecation warnings caused by passing null values to `strtolower()`.
- Plugin configuration radio button presentation.

### Changed

- Improved plugin configuration and installation packaging.

## [1.0.0] - Initial Baseline

### Added

- Initial Joomla system plugin implementation.
- Excel compatibility handling for UTF-8 CSV exports generated by RSForm! Pro directories.
- Initial installation and functional testing.
