# Changelog

All notable changes to Ceebl RSForm CSV Export will be documented in this file.

The project follows the principles of [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and intends to use [Semantic Versioning](https://semver.org/).

## [Unreleased]


## [1.1.0] - 2026-10-17

### Documentation

- Add README, changelog, and GPL-2.0-or-later licensing information.

### Added

- Configurable Excel UTF-8 compatibility fix.
- Optional CSV download restrictions based on Joomla user groups.
- Configuration for selecting authorized user groups.
- Optional hiding of CSV export buttons for unauthorized users.
- Server-side HTTP 403 protection for unauthorized directory CSV downloads.

### Fixed

- PHP deprecation warnings caused by passing null values to `strtolower()`.
- Plugin configuration radio button presentation.

### Changed

- Improved plugin configuration and installation packaging.

## [1.0.0] - Initial Baseline

### Added

- Initial Joomla system plugin implementation.
- Excel compatibility handling for UTF-8 CSV exports generated by RSForm! Pro directories.
- Initial installation and functional testing.
