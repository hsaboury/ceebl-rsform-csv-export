# Joomlog RSForm CSV Export

A Joomla system plugin that improves Microsoft Excel compatibility for Persian and other UTF-8 CSV exports generated by RSForm! Pro, with configurable access control for directory downloads.

## Features

- **Excel UTF-8 compatibility:** Improves the display of Persian and other non-ASCII characters in CSV files opened with Microsoft Excel.
- **Configurable encoding fix:** Enable or disable the Excel compatibility feature through the plugin settings.
- **Download access control:** Restrict RSForm! Pro directory CSV downloads to selected Joomla user groups.
- **Export button visibility:** Optionally hide CSV export controls from users without download permission.
- **Server-side protection:** Block unauthorized CSV download requests with an HTTP 403 response.

## Requirements

- Joomla 6.x (tested)
- RSForm! Pro (tested with version 3.4.10)
- PHP 8.4 (tested)

Compatibility with other Joomla, PHP, and RSForm! Pro versions has not yet been verified.

## Installation

1. Download the plugin installation ZIP package.
2. Log in to the Joomla administrator panel.
3. Navigate to **System → Install → Extensions**.
4. Upload and install the ZIP package.
5. Open **System → Plugins**.
6. Find **System - Joomlog RSForm CSV Export**.
7. Enable the plugin and configure its settings.

## Configuration

### Enable Excel UTF-8 Fix

Enabled by default.

Improves compatibility when opening RSForm! Pro CSV exports containing Persian or other UTF-8 text in Microsoft Excel.

### Restrict CSV Downloads

Disabled by default.

When enabled, CSV downloads are permitted only for users belonging to the selected Joomla user groups.

### Allowed User Groups

Select the Joomla user groups permitted to download CSV files.

This setting applies when download restrictions are enabled.

**Security note:** If download restrictions are enabled and no groups are selected, downloads are denied.

### Hide Export Buttons

Enabled by default, but effective only when download restrictions are enabled.

Hides the relevant CSV export controls from users who do not have download permission.

Hiding export buttons is a user-interface convenience, not a substitute for server-side access control.

## How It Works

The plugin integrates with the Joomla request lifecycle and targets RSForm! Pro directory CSV downloads.

For supported download requests, it can apply an Excel-oriented UTF-8 compatibility adjustment and enforce the configured group-based access restrictions.

The plugin does not modify RSForm! Pro source files.

## Security

Download restrictions are enforced on the server side. Users without permission receive an HTTP 403 response when attempting to access a protected CSV download directly.

The plugin's access restrictions apply to the supported RSForm! Pro directory CSV download route. They are not intended to replace Joomla's general access control system.

## Compatibility and Limitations

- Tested on Joomla 6 with PHP 8.4 and RSForm! Pro 3.4.10.
- Designed for RSForm! Pro directory CSV exports.
- Other export routes and formats are not covered by the verified functionality.
- Excel behavior may vary depending on the Excel version, operating system, and CSV import method.
